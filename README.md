# NEW-VEHICLE-TABLE (Google Apps Script)

Скрипт создает рабочую таблицу для учета поездок (заявок) и расчета движения средств.

## Что реализовано
- Меню **«Заявки»** в Google Sheets:
  - **Открыть панель заявок** — боковая панель со списком поездок и подробностями.
  - **Внести поездку** — модальное окно добавления поездки.
- Поддержка:
  - основного маршрута;
  - нескольких грузовых маршрутов;
  - стоимости и типа оплаты: **Наличные / Без НДС / С НДС**;
  - признака **холостой обратный путь**.
- Автоматический расчет:
  - топливо (8.1 ₽/км);
  - остаток после топлива;
  - лизинг 20%, ремонт 40%, водитель 40%;
  - налог 19% для доли водителя по грузам **С НДС**;
  - при холостом пути стоимость топлива на обратную дорогу делится пополам между водителем и компанией.

## Файлы
- `Code.gs` — серверная логика, расчеты, сохранение/чтение из листа `Trips`.
- `TripForm.html` — форма внесения поездки.
- `Sidebar.html` — панель заявок с просмотром деталей.
- `appsscript.json` — манифест проекта Apps Script.

## Как использовать
1. Создайте проект Google Apps Script, привязанный к Google Таблице.
2. Скопируйте файлы из репозитория в проект.
3. Перезагрузите таблицу — появится меню **«Заявки»**.
4. Вносите поездки через **«Внести поездку»**.
5. Просматривайте список и детализацию в **«Открыть панель заявок»**.
